# My SQL Practice & Business Analytics Portfolio

Welcome to my SQL practice repository! This project documents my journey in mastering data manipulation, database querying, and business intelligence analytics. 

## 🛠️ Technical Skills Demonstrated
* **Basic Querying:** SELECT, WHERE, DISTINCT, ORDER BY, TOP/LIMIT
* **Data Aggregation & Filtering:** GROUP BY, HAVING, Aggregate Functions (`SUM`, `AVG`, `COUNT`)
* **Advanced SQL Analytics:** Subqueries, Joins (INNER, LEFT, RIGHT), Window Functions (`ROW_NUMBER`, `RANK`, `DENSE_RANK`), and CTEs (Common Table Expressions)
* **Database Optimization:** Views, Temporary Tables, and Conditional Logic (`CASE` statements)

## 📊 Connection to Business Intelligence
I actively use these SQL scripting capabilities to extract, clean, and transform messy databases before loading them into reporting tools.
